# Changelog

All notable changes to ScreenForge are documented in this file.

## [1.0.0] - 2026-10-20

### Added
- Smart Auto-Zoom engine with click telemetry clustering and quintic camera glide transitions.
- Second-order spring-damper cursor physics simulation with customizable vector pointers and ripple waves.
- Studio Canvas renderer supporting multiple aspect ratios (16:9, 9:16, 1:1, 4:3, 4:5), luxury mesh gradients, and 2.5D perspective tilt.
- Multi-track timeline editor with trim handles, playhead scrub ruler, and zoom keyframe manipulation.
- 4K and GIF export engine supporting client-side WebCodecs and native hardware-accelerated FFmpeg profiles.
- Integrated screen and audio capture modal with real-time cursor tracking.
- Pre-packaged interactive demonstration suite for immediate experimentation.
- Comprehensive automated test suite for zoom boundaries, physics convergence, and aspect ratio metrics.
